\# Students Database Project



\## Description

This is a simple MySQL database created using XAMPP to store student information.



\## Features

\- Create database: students

\- Create table: student\_info

\- Store name, email, and age



\## Tools Used

\- XAMPP

\- MySQL

\- phpMyAdmin



\## How to Run

1\. Start Apache and MySQL in XAMPP

2\. Open phpMyAdmin

3\. Import the database.sql file

4\. View the student\_info table
